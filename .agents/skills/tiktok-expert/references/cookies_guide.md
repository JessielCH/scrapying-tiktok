# TikTok Cookies and Session Architecture Guide

## 1. Key Cookie Inventory

TikTok employs a specific set of cookies for session management, device tracking, abuse prevention, and security validation:

| Cookie Name | Scope / Domain | Critical Purpose |
| :--- | :--- | :--- |
| **`ttwid`** | Host / `.tiktok.com` | **TikTok Web ID.** Primary guest and session identifier issued by the backend after validating client fingerprints. Without it, API endpoints return HTTP 403 or empty responses (`status_code: 10202`). |
| **`sessionid`** / **`sessionid_ss`** | Host / `.tiktok.com` | **Primary Authentication Token.** Identifies logged-in users. Grants access to age-restricted media, followed private accounts, and personalized feeds. |
| **`msToken`** | `.tiktok.com` | **Signature Verification Token.** Dynamic cryptographic token generated by TikTok client scripts. Pairs with `X-Bogus` and `_signature` parameters. |
| **`tt_chain_token`** | `.tiktok.com` | Request chaining token to mitigate CSRF and correlate user navigation flows. |
| **`odin_tt`** | `.tiktok.com` | Unique web device/installation tracking identifier for analytics and rate-limiting. |
| **`csrf_session_id`** | `.tiktok.com` | CSRF token for state-changing operations (POST/PUT/DELETE). |
| **`store-idc`** / **`store-country-code`** | `.tiktok.com` | Regional data center routing indicators (e.g., `useast2a`, `maliva`, `sg`). |

## 2. Cookie Storage Formats

### Format 1: Playwright `storage_state` (JSON)
The native Playwright format containing cookies along with `localStorage` and `sessionStorage`:
```json
{
  "cookies": [
    {
      "name": "ttwid",
      "value": "1%7C...",
      "domain": ".tiktok.com",
      "path": "/",
      "expires": 1780000000,
      "httpOnly": true,
      "secure": true,
      "sameSite": "None"
    }
  ],
  "origins": []
}
```

### Format 2: Netscape HTTP Cookie File (`cookies.txt`)
Required by command-line utilities and external tools like `yt-dlp`, `curl`, `wget`, and Python's `http.cookiejar`:
```text
# Netscape HTTP Cookie File
# https://curl.se/docs/http-cookies.html
# Generated by TikTok Cookie Extractor

.tiktok.com	TRUE	/	TRUE	1780000000	ttwid	1%7C...
.tiktok.com	TRUE	/	TRUE	1780000000	sessionid	abcd1234efgh...
```

## 3. Extraction Strategies

### A. Real Browser Extraction with User Interaction (Recommended for Login)
- Launches Playwright with `headless=False` and a realistic desktop User-Agent.
- User scans the TikTok QR code from their mobile app (or signs in with credentials).
- The script detects the appearance of `sessionid` or redirection to the home feed.
- State is serialized immediately to both `cookies.json` and `cookies.txt`.

### B. Silent Bootstrap for Public Requests (Guest Mode)
- Sends an initial HTTP request using `curl_cffi` to `https://www.tiktok.com/` impersonating Chrome.
- Captures `Set-Cookie` headers from the response (including `ttwid`).
- Reuses this cookie jar for subsequent requests.
