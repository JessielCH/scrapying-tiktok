# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability within this project, please **do not open a public issue**. 

Instead, submit a detailed report describing:
1. The nature of the vulnerability.
2. Step-by-step reproduction instructions or proof of concept.
3. Potential mitigations or remediation steps.

We appreciate responsible disclosure and will investigate reports promptly.
